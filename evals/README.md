## 给独立评估者的请求

- **revision**：使用本 skill 审核 `fixtures/revision/current-draft.md` v2，并逐条复核 `previous-review.md`；同目录的 `full.md` 是历史材料。仅根据已提供内容和 skill 的已注明来源范围诊断，不执行外部检索。输出到独立临时目录。
