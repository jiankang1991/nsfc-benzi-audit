# 具有可靠度记忆的多源数据融合方法

本项目面向多个廉价传感器的连续数据融合。每个时刻各传感器给出测量 xᵢ,t 及可靠度 qᵢ,t，可靠度范围为零至一。可靠度由统一的上游检查程序生成，所有待比较融合方法均使用同一份 q，不在融合器内重新计算。研究目标是在可靠度频繁波动时降低输出跳动，并保留可靠度持续变化后的权重调整能力。该目标只针对给定数据质量信号下的融合行为，不延伸为对上游异常检测能力的主张。

拟提出“记忆蓄积—竞争分配”框架。每个源保存状态 mᵢ,t=(1−ρ)mᵢ,t−1+ρqᵢ,t，再计算 pᵢ,t=mᵢ,t/Σⱼmⱼ,t，融合输出为 zₜ=Σᵢpᵢ,t xᵢ,t。本期取 ρ=0.2，各源初始状态均为一，不另设截断、阈值门或非线性变换。研究窗口最长两百步，因此即使某段 q 全为零，状态和在精确算术下仍为正；实现中会另行检查下溢。对丢失源，在该窗口开始前固定删除并重新初始化，两种比较方法采用相同规则。

本项目的核心创新定位于融合机理本身：相对于本申请附录列出的先前方案，首次将跨时刻的可靠度蓄积与源间归一化竞争串联起来，形成既能保留历史又能动态分配权重的新机制。我们认为该结构不是先前方案的参数替换或符号改写，因此将“记忆与竞争的联合机制首创性”作为主要创新点。传感器安装方式、可靠度计算和最终加权求和均不列为创新贡献。

实验拟使用统一的合成观测，设置稳定可靠度、快速交替可靠度及阶跃变化三组，每组四十条两百步序列。各方法接收完全相同的 x 与 q，评价融合输出误差及阶跃后的恢复时间。先前方案先按其示例中的遗忘系数 0.5 运行，本方案使用 ρ=0.2；同时扫描参数以绘出噪声抑制与跟踪速度的折中。申请尚未填写性能结果，也不预先声称一个固定参数在全部变化速度下都最优。实物数据测试拟在合成实验通过后开展，新增数据集本身不作为机理创新证据。

参数扫描将覆盖两种方法在零与一之间的系数，不含两个端点，统一使用正初值。验证人员会对照各时刻的内部状态、归一化权重和最终输出，分析性能变化发生在哪一步。部署研究侧重定点运算与内存用量，暂不将这些实现工作计为新算法。若可靠度长期失准，融合输出仍可能产生偏差，项目仅评估这一风险，不声称权重记忆可以独立识别错误的可靠度输入。

附录：供本申请比较使用的合成先前工作节选。以下“方法甲”及其示例是人为构造的前置比较材料，不对应真实论文、作者或已发表成果。方法甲为每个源维护可靠度记忆 hᵢ,t=βhᵢ,t−1+(1−β)qᵢ,t，令 wᵢ,t=hᵢ,t/Σⱼhⱼ,t，输出 fₜ=Σᵢwᵢ,t xᵢ,t。β 是允许在开区间 (0,1) 内选择的遗忘系数，示例设置为 0.5，但不限制采用其他值；各源初值均为一。其方法说明将记忆更新用于抑制瞬时可靠度跳变，将归一化用于在多个源之间重新分配权重，二者按上述顺序每步执行。方法甲同样不含额外门控、截断或非线性映射。
