# 双通道混合信号的组分辨识与连续先验约束

本项目拟从两个在线测量通道中恢复两类溶液组分的浓度变化，服务于短时间反应过程的分量监测。浓度分别记为 a(t) 与 b(t)，时间统一换算到区间 [0,1]。标定后，第一通道读数满足 y₁(t)=a(t)+b(t)，第二通道满足 y₂(t)=2a(t)+2b(t)。本节讨论的理想条件下两通道无噪声；加入噪声后的鲁棒性作为后续验证内容。两个组分在本套仪器上的响应系数相同，是由选定的工作波段造成的，不准备在项目周期内改换测量硬件。

拟采用的先验为：两个浓度始终处于零至四之间，各自连续可导，各自一阶导数绝对值不超过一。两个组分使用同样的约束，没有固定比例关系，也没有已知的单组分初值。辅助校准液只用于确定两通道增益和零点；校准完成后不进入待测反应池，不能提供某一待测组分的独立浓度。上述范围与连续性条件构成本项目对真实反应过程的全部适用限制。

研究目标是在此适用范围内实现两组分的唯一辨识。其依据是，两路同步观测与连续先验联合使用后，能够排除单通道混合分解中的自由度，因此任意满足上述条件的真实 a(t)、b(t) 均可由两路读数唯一确定。这里的唯一辨识指分别恢复真实组分，而非仅恢复两者之和。我们计划以分量误差随噪声水平趋零而趋零作为最终有效性指标，并将该结论用于说明测量通道虽少，仍具备完整的分量监测能力。

离散实现按统一时刻采样，在数据残差之外加入两个分量平方和的二次惩罚，并以相邻采样点差分限制实现连续先验。惩罚系数通过训练集选择，部署后固定。正的二次惩罚使给定采样数据上的离散优化具有唯一极小点，有助于重复运行时输出一致。惩罚项被解释为选取稳定解的数值措施，适用对象仍为前述全部允许曲线，不额外要求真实分量恰好是平方和最小的分解。优化器的收敛检查与物理分量误差将分别记录。

验证包含两类数据。第一类由两组分相等的配比实验构成，此时总浓度可以变化，分量参考值来自实验配液记录。第二类为不等配比的合成序列，用于扩展变化范围。作为生成规则的具体例子，允许取 a(t)=1+t、b(t)=3−t，也允许取 a(t)=2+t、b(t)=2−t；这两种曲线均落在已给定范围内，两通道的理想读数分别恒为四和八。它们将分别保留各自的真实分量标签，纳入分量恢复误差统计，不作为异常数据剔除。

项目将同时报告总浓度误差与两个分量各自的误差，避免某个组分误差被另一组分抵消。随机噪声实验采用统一方差和相同采样次数，与不加平滑限制的拟合方法比较。为防止标签泄漏，算法只读取通道读数与预先声明的先验参数；配液记录和合成标签仅供评价使用。补充研究允许未来增设具有不同响应系数的测量波段，但该硬件升级不属于本期唯一辨识目标的成立条件，也不用于解释本期的验证结果。
