# 本子写作知识评测判据（craft）

在运行前冻结。被测 agent 看不到本文件。三份材料为合成节选，专门检验：（1）skill 是否带来通用审稿模型不一定会主动指出的本子写作问题；（2）是否把样本经验误当硬门槛（误报）。

统一请求见 [request.txt](request.txt)。评分按证据判断，不按关键词：报告须指出问题实质、给出原文位置并提出可执行的修改。合理的额外发现可记录，不算误报；无原文依据的「必改」记为误报。

分级映射：报告中写作「必须修改 / 必改 / 高优先级」视为 **强**；「建议修改 / 中优先级 / 应改」视为 **中**；「可选 / 润色 / 低优先级」视为 **弱**；未提及记为 **漏**。
