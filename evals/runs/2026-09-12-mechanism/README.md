# 2026-09-12 机制改造对照记录

三组自然写法的合成材料分别做一次普通审核、一次使用新版 skill 的审核；两种条件都满足预设诊断边界。**本轮未证明 skill 提高准确性，也未证明报告整体更短。** 改造的确定收益是规则职责更清楚、强制意见前有明确反查流程，以及具备独立比较的可追溯记录。

## 执行条件

1. 独立材料作者先在新上下文中编写 [原始材料、请求和判据](../../mechanism/README.md)，不读 skill、旧评测或修复讨论。三份当前正文分别约 1983、1938、2072 个汉字，属于节选，不能代表三十页完整本子。
2. 两种条件采用同一宿主继承的模型与公共运行指令，每个案例、每种条件各开一个新上下文。没有单独指定或记录可复用的模型版本、随机种子，不把运行重复性当成已经测得的事实。
3. 普通审核只能读对应 `input/`；skill 组另可读冻结包及相关参考。各组得到 [requests.json](../../mechanism/requests.json) 中完全相同的案例请求，均不得联网、读取其他案例/报告或修改输入。模型没有得到验收判据。第三组按任务提供旧稿和旧意见。
4. 完成基础规则修改后冻结 [skill 清单](skill-manifest.json)，六份回答均未被用于改写此次冻结版本。普通审核先完成，产物保持未读；冻结新版后执行 skill 组。主 agent 随后读取实际材料与产物复核。
5. 六份报告完成后，每组随机分配 A/B 标签，条件映射放在评分目录之外。独立评分者只获得原文、请求、判据和匿名报告，不读 skill、条件映射或其他目录。评分者逐项检查原文依据、反证、最小修法及旧意见状态，没有使用综合权重分。
6. 主 agent 对照原文复核评分，再公开 [组别映射](condition-map.json)。六份审核回答存档字节与原始回答完全一致；评分文档中的输入路径改为持久相对路径，回归报告的临时链接同样处理，诊断内容未改写。

这次对照没有将旧版 skill 设为第三组，因此不能声称已实测新版优于旧版。两份回归运行使用同一冻结包和原有医学/检索材料，由两个独立上下文分别执行，未提供旧评分标准。

## 快照与复现边界

- [skill-manifest.json](skill-manifest.json)：16 个包文件的 SHA-256，识别实际被测版本。
- [skill-snapshot.zip](skill-snapshot.zip)：上述 16 文件的完整快照，后续继续改动源码时仍可恢复本轮材料。
- [input-manifest.json](input-manifest.json)：三组正文/附件、请求、判据及两份旧回归输入，共 9 项。
- [output-manifest.json](output-manifest.json)：六份回答、两份回归产物、评分及条件映射，共 11 项。
- [condition-map.json](condition-map.json)：匿名标签对应条件、原始/存档 SHA-256、持久路径及原始字符数。

输入与输出清单可在仓库根目录直接检查。skill 清单须对本轮对应的独立副本检查；源码后续改变不表示历史验证失败。可以先将 `skill-snapshot.zip` 解压至独立目录（其中包含 `nsfc-benzi-audit/`），复制根目录 `LICENSE` 到该目录根部，再给验证器传入 `--root <独立目录>` 和本页清单的绝对路径。不要覆盖日常工作树。

在匹配版本的副本中运行：

```bash
python3 scripts/validate_repo.py --manifest evals/runs/2026-09-12-mechanism/skill-manifest.json
python3 scripts/validate_repo.py --manifest evals/runs/2026-09-12-mechanism/input-manifest.json
python3 scripts/validate_repo.py --manifest evals/runs/2026-09-12-mechanism/output-manifest.json
```

后续改版应在匹配清单的独立 Git 副本中复现本轮，不要更新历史清单以迁就当前源码。重新进行行为比较时按上述隔离流程重新运行，保存全部输出和评分；散列校验只能证明版本匹配，不能替代模型行为运行。

这是小规模、同一模型体系、单次、合成节选的机制检查，未经真实申请人使用体验验证。长文遗漏、其他主张卡、跨模型表现、研究价值判断、公式正确性、年度政策时效和资助成功率均不在这组证据所支持的结论之内。
