# Semantic assessment protocol

Use the independently authored rubric and raw source as evidence, not an exhaustive answer key. Identify required findings, misses, unsupported strong findings, valid additional findings, smallest actionable repairs, source locators, and preserved valid arrangements. Keep optional clarification distinct from defects. Do not use a combined weighted score or infer accuracy from the number of examples. The long-material author proposed an optional 100-point weighting; this assessment does not adopt it. Evaluate all report variants under the same criteria and keep condition labels hidden from the assessor.

For the long task, also record main-report Hanzi count against the requested approximate 1800-character budget, appendix presence and whether it adds evidence rather than duplicating the main recommendation. Reading coverage is judged only as a reported scope with source support; a generated index does not establish semantic reading. Accept no appendix when the main report already contains adequate evidence. State rubric ambiguities before counting an additional strong finding. A downstream edit mapping can test whether a recommendation is concrete, but does not establish real applicant usability or scientific validity.
