## 结论与限制

- **检出率三组相同**：预设问题四组全部检出，陷阱全部没有被判强。本批材料的问题写得明显，当前模型不加载 skill 也能找出，**不能据此宣称 skill 提升了检出率**。
- **恢复写作规则没有引入误报**：`19917ae` 删减规则的主要理由是担心误报；恢复后的 NEW/NEW2 在 8 个 02 陷阱和 3 个 03 陷阱上都没有误报，分级比 N 更克制（02 必改数 12 → 3）。
- **可观察的差别在表达**：NEW 直接使用限定语追踪、六问漏斗、新观测体制四要素、同构对照表、对照式实证图、转方向分层等本子写作框架给出修改骨架；N 和 R2 靠通用审稿能力得出类似结论，但少了这些对应本子写法的修改抓手。这一点是定性观察，没有打分。
- **篇幅**：NEW 首次运行明显偏长（N 的 1.8–2.3 倍），根因是逻辑图、覆盖表、一致性矩阵、分章节要点重复同一批问题。收紧模板后 NEW2 在 02 上短于 R2，在 01 上仍比 R2 长约 38%。
- **局限**：材料由主 agent 编写且知道规则内容；02 判据有缺陷；单模型、单次运行；非盲评；没有真实三十页申请书或 PDF/原图输入。需要更难、写作问题更隐蔽的真实匿名本子才能检验 skill 的增量。
