本轮只使用合成材料，无真实申请书、真实项目查询或实验运行。请求与验收判据见 [评测说明](../../README.md)；判据未交给前向评估者。

## 执行与版本

首次试运行使用三个新上下文子 agent：一个做 revision，一个做 medical，一个分别做 lookup 与 uncovered。后两项由同一评估者分开分析，不是独立重复样本。评估者只得到相应原始材料、skill 独立副本与用户请求，不读取仓库修复讨论、审核结论、验收答案或其他评估者的产物。所有试运行禁止外部查询，产物先写入隔离的临时目录，再由主 agent 对照判据验收。

初次冻结后，收尾检查修改了 `question-distillation.md` 的问题来源/串行组织措辞，以及 `representative-works.md` 的作者位次/发表场所示例；重新冻结最终版本，并用另一个新上下文子 agent 补跑 revision。其余 skill 文件及全部用例输入未变。

- [初次快照 SHA-256](initial-manifest.json) 与 [最终快照 SHA-256](final-manifest.json) 均使用仓库相对路径。
- [快照差异补丁](final-to-initial.patch) 可在最终 skill 的独立副本上还原初次版本；已通过 `git apply --check --unidiff-zero`。该补丁不含上下文行，实际还原时也须使用 `git apply --unidiff-zero`。不要在日常工作副本中应用此补丁。
- 报告只做存档路径处理：临时绝对路径改为仓库相对路径，Markdown 链接的编辑器行号后缀移除，初次复审额外归档的旧报告副本指回同内容的测试输入。未改写诊断结论。
- 快照哈希用于定位版本；行为结论来自实际报告的人工语义验收，未用关键词匹配代替判断。
