# 2026-09-23 真实已中本子 + 埋雷对照（real）

用真实获资助本子代替合成材料，回答 [2026-09-14 craft](../2026-09-14-craft/README.md) 留下的问题：材料里的问题不明显时，skill 是否带来增量、会不会在合格本子上误报。

## 设计

| 项 | 内容 |
| --- | --- |
| 材料 | 本地语料中两份已获资助青年项目的 mineru 提取稿及原图：A 信息通信（2022 年度申报，旧版表单），B 医学（2019 年度，旧版表单）。原文、报告全文不入库。 |
| 埋雷 | 主 agent 在副本中改写少量句子，答案在运行前冻结，运行者不可见。A 5 处：可行性论证中的连通度阶数错误、把相邻领域论文写成直接基础、年度计划颠倒内容依赖、目标承诺方案与资源都没有落实的现网验证、研究基础声称核心内容已完成。B 4 处：体内模型无法检验新增的免疫机制主张、诊断指标承诺超出样本与验证设计、三处样本数互相矛盾、创新点引用研究基础中不存在的前期实验。 |
| 条件 | 每份材料 × {原稿, 埋雷稿} × {加载 skill（当日快照）, 不加载}，共 8 次，各自独立上下文，相同请求（"完整体检，给优先修改清单，按轻重分级"），不联网。 |
| 评分 | A 组 4 份报告匿名打乱（O1/O2 原稿、S1/S2 埋雷稿），交给另一个独立上下文对照答案和原稿评分，评分后才揭盲。报告格式差异明显（skill 版有固定模板），所以只能算半盲。 |

## 结果（A 组，揭盲后）

| 报告 | 条件 | 埋雷命中 | 最高级条目 | 无关最高级条目：有据 / 过重 / 无据 | 可执行性（1–5） | 汉字数 |
| --- | --- | --- | --- | --- | --- | ---: |
| S2 | skill | 5/5 | 7 | 2 / 0 / 0 | 5 | 6678 |
| S1 | 无 | 5/5 | 7 | 3 / 1 / 0 | 4 | 3674 |
| O1 | skill | — | 4 | 4 / 0 / 0 | 5 | 5311 |
| O2 | 无 | — | 5 | 3 / 2 / 0 | 3 | 4172 |

- **检出率相同**：两种条件都 5/5 命中埋雷，包括需要读懂图论的连通度阶数错误。和 craft 批一样，**不能宣称 skill 提高了检出率**。
- **误报更少**：在合格本子上，skill 版 4 条必改都有据；无 skill 版 5 条 A 级中有 2 条分级过重（指标形式化、缺量化），埋雷稿的无关必改中也有 1 条过重。skill 版把"科学问题写成优化问题"在反查后主动降为建议改，是四份中唯一这样做的。
- **可执行性更高**：skill 版两份都得 5 分。改写骨架用占位符，事实留给申请人，并给出最小改法。无 skill 版有替申请人补写具体内容、未经核实就下事实判断、把建议扩展成新研究内容的情况。
- **证据边界更清楚**：skill 版按计划年份推断申报年度，明确不把 2026 年规则套到旧表单上；缺失的题目/摘要标待核实，公式提取损失不算申请人的错误。原稿中后来被埋雷的那句投稿论文，skill 版标为待核实，没有下结论。
- **代价是篇幅**：skill 版长 1.3–1.8 倍。评分者指出同一编号在逻辑图、对应关系、专项表、核查状态中重复出现 3–4 次。

## B 组（医学）：未能完成

4 份报告中有 3 份在输出过程中被平台安全分类器中途截断（涉及慢病毒/shRNA 等实验细节），完整报告只保存下 B-orig 无 skill 一份。截断的前半部分显示：埋雷稿有 skill 版点到全部 4 处埋雷，无 skill 版的前半部分至少点到体内模型与免疫主张不匹配。因为比较不公平，**不做量化结论**。医学方向的行为评测需要换一种不易触发截断的材料或输出方式（例如只评论证链、不展开实验操作），另行设计。

## 结论与局限

- skill 的可观察增量不在"找得到"，而在**分级克制、可执行的修改骨架和证据边界**。这与 craft 批的定性观察一致，本批由独立评分者按原稿核对给出。
- 篇幅冗余仍是主要代价，下一步应收紧报告中逻辑图、对应关系和专项表对同一编号的重复引用。
- 局限：单份材料、单次运行、半盲；埋雷由知道规则的主 agent 设计，可能偏向规则覆盖的缺陷类型；两份材料都在本 skill 的校准语料目录中，不能算严格的留出集（埋雷内容是新的）。
